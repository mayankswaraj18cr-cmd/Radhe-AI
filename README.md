## Architecture — 7 Layers
1. User Interface Layer — text, voice, API, embedded
2. Intent Recognition Layer — disambiguation, memory integration
3. Reasoning & Generation Layer — transparent chain-of-thought
4. Verification Layer — fact-check, confidence scoring
5. Memory Layer — 5 dimensions: conversational, episodic,
   semantic, procedural, project
6. Agent Orchestration Layer — 7 specialised agent types
7. Integration Layer — APIs, plugins, ecosystem connectivity

## Memory Architecture — 5 Dimensions
- Conversational Memory — session context (ephemeral)
- Episodic Memory — specific past events (timestamped, searchable)
- Semantic Memory — user profile, preferences, goals (encrypted)
- Procedural Memory — behavioural patterns (continuously refined)
- Project Memory — active work state (persists until closed)
